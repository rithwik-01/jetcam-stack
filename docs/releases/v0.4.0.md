# JetCam Stack v0.4.0 — Validated camera pipeline

## English release notes

JetCam Stack v0.4.0 is the first public source release. It delivers the validated stages 1–4 of the Jetson Orin Nano + IMX219 camera project: hardware and media-topology baselining, direct V4L2 RAW validation, an IMX219 test-pattern driver enhancement, and VLC-compatible H.264 video delivery.

### Highlights

- Validated the full IMX219 → NVCSI → VI → V4L2/Argus data path on JetPack 6.2.3 / L4T R36.5.0.
- Added `jetcam-raw-test`, a C++17 V4L2 MMAP utility with mode enumeration, FPS/drop statistics, timeouts, sequence validation, and RG10 frame export.
- Completed a 600.025-second 720p60 run: 36,076 frames at 60.115 FPS with zero drops, discontinuities, buffer errors, or timeouts.
- Added standard `V4L2_CID_TEST_PATTERN` support to NVIDIA's R36.5 IMX219 OOT driver and supplied a matching IMX219-C overlay patch.
- Added `jetcamd`, a GStreamer C++ service using Argus/ISP, NVMM, `nvvidconv`, and x264 software H.264 encoding.
- Validated 720p60 and 1080p30 MPEG-TS/UDP playback in VLC, RTSP/TCP streaming, JPEG snapshots, and a 30-minute 720p60 stability run.
- Published sanitized, checksum-protected hardware evidence and bilingual top-level documentation.

### Hardware note

Jetson Orin Nano does not include NVENC. This release intentionally uses x264 software encoding; `nvv4l2h264enc` is not expected to be present.

### Known limitations

- Automatic no-frame detection and bounded pipeline recovery are not implemented yet.
- `jetcamctl` and systemd service integration are not included yet.
- The driver patches target NVIDIA Jetson Linux R36.5 and must not be applied blindly to another release.
- Prebuilt binaries and NVIDIA components are not distributed. Build on the target Jetson using separately installed official dependencies.

### Release assets

GitHub's tag-generated source archives are the recommended assets. If attaching a custom archive, include only the source tree from tag `v0.4.0` plus its SHA-256 checksum. Do not attach local plans, credentials, RAW captures, proprietary NVIDIA packages, or prebuilt kernel modules.
